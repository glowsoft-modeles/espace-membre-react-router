# Espace membre pour React Router

Une zone réservée derrière une connexion par session.

Modèle de départ Bastide (`espace-membre-react-router`), écrit par Glowsoft. Il se construit et se déploie sans modification ; la campagne hebdomadaire le construit avec des valeurs d'essai.

## Variables

Le déploiement en un clic les demande avant la construction ; copiez `.env.example` pour un essai local.

- `SESSION_SECRET` (requise) : Une chaîne aléatoire d'au moins 32 caractères qui signe les sessions. À obtenir ici : https://cheatsheetseries.owasp.org/cheatsheets/Session_Management_Cheat_Sheet.html
